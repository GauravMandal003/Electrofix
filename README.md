🔧 ElectroFix

«Home Appliance Repair, Shopping & Used Appliance Marketplace»

ElectroFix is a full-stack platform that brings appliance repair services, online shopping, and used appliance buying/selling together in one place.

✨ Features

- 🔧 Repair Services — Request appliance repair services
- 🛒 Online Shop — Browse products and manage cart
- ♻️ Used Appliances — Buy and sell used appliances
- 💳 Online Payment — PayPal payment integration
- 👤 User Account — Manage profile, orders and activities
- ❤️ Wishlist — Save favorite products
- 💬 Chat — Customer communication
- 🛠️ Admin Dashboard — Manage the platform

🛠️ Tech Stack

Frontend: React • Vite • JavaScript • CSS
Backend: Node.js • Express.js
Database: Firebase / Firestore
Authentication: Firebase Authentication
Payment: PayPal
Icons: Lucide React


🔄 Core Flow

Repair / Product / Used Appliance
            ↓
       Booking / Cart
            ↓
         Payment
            ↓
       Confirmation
            ↓
        User Account
